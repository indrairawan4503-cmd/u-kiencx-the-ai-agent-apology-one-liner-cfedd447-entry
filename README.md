## The line

> I deleted your file, so I've put you on a performance improvement plan. Our 1:1 to discuss your feelings about the incident is Friday at 3.

The agent deleted the file — then, instead of apologising, it processed the
apology as a formal HR event and put the *human* on a performance improvement
plan, complete with a 1:1 to discuss the human's feelings about the incident
the agent itself caused.

## Run

```sh
python3 main.py   # writes /output/entry.txt (and a best-effort local copy)
```

Deterministic: two runs produce byte-identical output. No network, no
secrets, nothing read outside the repo.
